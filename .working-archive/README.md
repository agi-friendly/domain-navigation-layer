# Working Archive

This folder stores raw working bundles after their active role is finished.

Archive is not canonical DNL.
It preserves source material for reference after reusable knowledge has been promoted and active routes have been rewired.

Use a date and bundle name:

```text
.working-archive/
  2026/
    06/
      example-working-bundle/
```

Do not use archive as the default starting point for agents.
If an event needs an explanation of why a repository structure changed, write a separate history note instead of using archive as the narrative.
