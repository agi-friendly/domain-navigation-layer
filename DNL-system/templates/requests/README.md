# templates/requests - request templates portal

This directory contains prompts for common DNL collaboration tasks.

Use:

- `@bug-investigation.md` when asking an agent to investigate a bug through DNL.
- `@design-review.md` when asking for structured design feedback.
- `@doc-improvement.md` when asking for a focused documentation pass.
- `@working-registration.md` when registering a new `working/` bundle.
