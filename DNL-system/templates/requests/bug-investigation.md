# Bug Investigation Request Template

Use this template when you want an AI to investigate a bug. Keep the request focused on reproduction, environment, symptoms, logs, and expected behavior.

## What to include
- Reproduction steps
- Environment details
- Symptoms
- Logs, screenshots, or other evidence
- Expected result
