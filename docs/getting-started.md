# Getting Started

1. Read the root `@repo-README.md`.
2. Open `@docs-index.md` and choose the page that matches your task.
3. If you are using an automated agent, read `@repo-AGENTS.md` before editing anything.
4. If you are changing navigation or maintenance rules, read `@dnl-system.md` next.
5. Keep each change focused and update links in the same commit.
6. Run `git status --short --branch` before you stop.

No build step is required for the documentation itself.
