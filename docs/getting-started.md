# Getting Started

1. Read the root [README.md](../README.md).
2. Open the [documentation index](index.md) and choose the page that matches your task.
3. If you are using an automated agent, read [AGENTS.md](../AGENTS.md) before editing anything.
4. If you are changing navigation or maintenance rules, read [DNL-system](../DNL-system/README.md) next.
5. Keep each change focused and update links in the same commit.
6. Run `git status --short --branch` before you stop.

No build step is required for the documentation itself.
